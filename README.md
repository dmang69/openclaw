## Installation (Windows 11 .exe)

This project includes a Windows-ready `.exe` build for local execution. The installer bundles required components and runs without external dependencies. After installation, the application launches as a standalone local-first agent environment with deterministic behavior and reproducible state transitions.

### Steps

1. Download the latest `.exe` from the Releases page.
2. Run the installer and follow the on-screen prompts.
3. Launch the application from the Start Menu or desktop shortcut.
4. The system initializes with local configuration, persona files, and agent modules pre-loaded.

This installation method is intended for users who need a clean, offline-capable, audit-friendly execution environment on Windows 11.
